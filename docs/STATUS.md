## §8 Критерии успеха v1.0

| Критерий | Состояние |
| --- | --- |
| Письма из ящиков появляются в диалогах без дубликатов | ✅ дедупликация по provider id и `Message-ID`, покрыта тестами |
| Ответы сохраняют связь с цепочкой | ✅ `In-Reply-To` + `References`, ответ остаётся в диалоге |
| Отправка из другого клиента склеивается в ту же переписку | ⚠️ логика есть (`ConversationRouter`), проверена юнит-тестами; на живом ящике не проверялась |
| Работа без сети: вся история из кеша | ⚠️ чтение полностью локальное, **но отправка без сети падает** в `failed` без очереди на повтор |
| Ошибки провайдера не приводят к потере черновиков | ⚠️ текст письма остаётся и доступен для повтора, **но черновик не сохраняется при закрытии экрана** |
| Обе темы, разные экраны, масштабирование текста | ✅ тема и контраст под тестом, вёрстка проверена на 360×640 |

## Итого

Готово к использованию: чтение, поиск, темы, избранное, хранилище,
синхронизация Gmail, **отправка и ответы из Gmail**.

Не готово, по приоритету:

1. **IMAP/SMTP, Яндекс, Mail.ru, Outlook** — спринт 06, без него тестировать
   на своих ящиках, кроме Gmail, нельзя.
2. **Вложения** — модель есть, UI нет.
3. **Черновики и офлайн-очередь отправки** — сейчас потеря черновика при
   закрытии экрана и `failed` без автоповтора при обрыве сети.
4. **Архив/удаление на сервере** — сейчас только локально, без предупреждения.
5. **Фоновая синхронизация и уведомления** — спринт 07.
6. **FTS-поиск, фильтры рассылок, локализация** — спринт 08 / 02.

## 6. Что придётся переделать, а не дописать

### 6.1. `lib/core/utils/update_check.dart` — старый источник данных

Сейчас: `GET /repos/.../commits?sha=<ветка>&per_page=1` → узнаёт только sha.

По ТЗ §3.1 нужно: `GET /repos/.../releases?per_page=10` → узнаёт sha **и**
ссылку на APK, размер, список изменений, дату.

Значит файл не «дополняется», а переписывается: модель `UpdateStatus`
расширяется полями `downloadUrl`, `sizeBytes`, `notes`, `tag`. Существующие
тесты на коммиты (8 штук в `test/core/update_check_test.dart`) нужно перевести
на ответ релиза; часть из них остаётся как проверка резервного пути §3.2.

## 10. Риски, о которых лучше знать заранее

| Риск | Почему важно |
| --- | --- |
| Первая установка после Sprint 09 может потребовать удаления приложения | если подпись APK сменится (сейчас debug-keystore генерируется заново на каждом раннере) — ТЗ §7 предусматривает стабильный keystore в секретах **до** включения обновлений |
| Размер APK ~194 МБ | загрузка по мобильной сети дорогая → настройка «только Wi-Fi» не украшение, а необходимость |
| GitHub rate limit: 60 запросов/час на IP | при проверке на каждом старте можно упереться → отсюда правило «не чаще 6 ч» |
| Android 8+ требует разрешения на установку из неизвестных источников | без `REQUEST_INSTALL_PACKAGES` установка молча не начинается |

# Продукт Mellow 1.0

Полная инженерная спецификация — исходный документ проекта. Здесь его краткая
рабочая версия: что строим, для кого, в каких границах и чем не являемся.

## 1. Что это

Mellow — кроссплатформенное мобильное приложение для общения по электронной
почте с пользовательским опытом мессенджера. Подключается к существующим ящикам,
превращает переписку в диалоги. Получателю не нужно ставить Mellow.

## 2. Цели

1. Упростить повседневную почту.
2. Сделать email похожим на переписку в мессенджере.
3. Работать с популярными провайдерами.
4. Хранить историю локально и открывать её без сети.
5. Быть независимым от конкретного почтового сервиса.

## 3. Аудитория

Люди, которым неудобны классические почтовые клиенты; те, кому нужен
альтернативный канал; владельцы нескольких ящиков; любители минимализма.

## 4. Границы продукта

Mellow **не** почтовый сервер и не мессенджер с собственной доставкой.
Следствия:

* скорость доставки зависит от провайдера;
* работа требует доступности почтовой инфраструктуры;
* лимиты отправки задаёт сервис;
* подтверждения доставки и прочтения обычным email не гарантируются;
* мгновенные push для всех провайдеров без серверной инфраструктуры невозможны.

## 6. Ключевые продуктовые правила

1. Не реализовывать все провайдеры одновременно: сначала идеальный Gmail, затем
   IMAP, затем Graph.
2. Не обещать мгновенную доставку.
3. Не строить собственный сервер преждевременно, но оставить расширяемую
   архитектуру уведомлений.
4. Адрес — идентификатор адресата, не человека. Объединение — только вручную или
   по надёжному подтверждению.
5. `Отправлено` = сервер принял письмо.
6. Фильтрация (Focus Mode) не удаляет оригиналы.

## 7. Интерфейс

Четыре раздела: **Диалоги**, **Люди**, **Избранное**, **Настройки**.
Ключевые экраны: список диалогов, профиль человека, переписка, Composer,
настройки (Аккаунты, Внешний вид, Уведомления, Синхронизация,
Конфиденциальность, Хранилище, О приложении).

Детали — `docs/UI_GUIDELINES.md`.

## 8. Критерии успеха v1.0

* Письма из подключённых ящиков появляются в диалогах без дубликатов.
* Ответы сохраняют связь с исходной цепочкой.
* Отправка из другого клиента склеивается в ту же переписку.
* Работа без сети: вся история доступна из кеша.
* Ошибки провайдера не приводят к потере черновиков.
* Обе темы, разные размеры экрана, масштабирование текста.
